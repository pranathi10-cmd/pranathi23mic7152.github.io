# Naga Pranathi Portfolio

## Run in VS Code
1. Open this folder in VS Code.
2. Open `index.html`.
3. Right-click the file and choose "Open with Live Server" if you have the Live Server extension.
4. If you do not have Live Server, you can double-click `index.html` and open it in a browser.

## Files
- index.html - portfolio content
- style.css - design and responsive layout
- script.js - menu, cursor glow and scroll animations

Replace/add your own resume, GitHub URL, project links, and profile image if you want them.
